# 两周版本交付验收

日期：2026-10-21（Asia/Shanghai）。这是设计书定义的两周功能切片，并非声称实际开发经过了两个自然周。

## 中文适配增量验收

本轮将商品卡片、分类筛选、比较表、收藏清单及 Agent 推荐改为中文展示，原始事实与来源证据仍保留英文。中文数据使用独立、绑定源哈希的展示缓存，缓存失效时采用保守中文类型回退，不补齐未知价格和规格。

更新后的完整质量检查为 **328 项测试通过，核心行覆盖率 87.82%**；格式、lint、mypy、依赖一致性和构建均通过。最新质量结果在 `reports/quality/`；适配前的质量结果和交付清单已保存在 `reports/archive/pre_localization/`。

完整翻译覆盖与真实接口核验入口为 `reports/localization/api_acceptance.json`；实际浏览器交互与截图在 `reports/localization/`。构建配置、失败重试和翻译限制见 `reports/localization_build.json` 与 `docs/catalog_localization.md`。覆盖和数值校验不能证明语义翻译准确率，译文仍需提供原文核对入口。

下文的 20 场景、初版视频和 GPU5 资源记录属于适配前的 MVP 基线，不作为本轮中文质量证据。中文构建期间在线服务使用 GPU1、离线翻译使用 GPU5，合计两张卡；构建结束后仅保留在线服务。

设计中的2k—5k目录目标达到。自制fixture缩为3件专门覆盖缺价/缺品牌/材质差异，不用100件重复合成商品假装真实效果；规模展示使用真实3,000件。Embedding复用服务器已有4B编码器，代替设计中可选0.6B，减少下载和新依赖；生成模型仍严格使用用户指定1.7B，两个模型共用一张A6000。

## 原 MVP 真实运行结果（中文适配前）

最终全量自动化测试 **220 项通过**，纳入统计的核心模块行覆盖率 **86.74%**；格式、lint、mypy、依赖一致性与wheel/sdist构建全部通过。真实一键启动、停止、再次启动均成功，重启后的本地模型聊天再次返回5件满足20美元预算且有证据的商品。三服务现保持ready；资源核验仅有物理GPU5上的本项目模型进程。详见 `reports/launcher_smoke.json`、`reports/runtime_verification.json`。

20/20开发场景通过；其中20个去重聊天回合中16个产生真实模型token、4个由明确业务规则澄清，共30次生成请求。场景包括中英文、上/下/区间预算、排除项、多轮预算、比较缺失属性、币种澄清、无意义输入、零预算、反馈幂等、跨会话拒绝、约束注入防护、逐字段事实与聊天幂等。

当前主提示词20/20协议用例通过，衡量JSON、动作与必要参数。它不等于商品相关性或模型自由回答正确率。探索阶段自由回答曾编造价格，故最终商品事实使用证据模板。开发场景也暴露过预算变更误路由，修复后使用同一套件复测。15/20、19/20失败报告及旧提示词报告都保留在 `reports/archive/`。

源文件前缀不保证代表性；1,539件具有历史美元价格，1,461件未知。严格预算会排除未知价格。采集时价格与商家描述不保证当前有效。少量真实GPU探针与20个场景只作为本机开发观察，不声称检索NDCG、线上业务增益或生产SLA。

## 工程与复现边界

自动化检查含格式、lint、类型、隔离的CPU单元/服务测试、核心模块覆盖率门槛80%、依赖一致性与wheel/sdist构建。生成服务和UI从核心覆盖率口径中排除，分别有独立单测、真模型运行保护及真实浏览器验证。GitHub Actions配置已准备，尚未在远程CI执行；当前结论来自本机my_rec。

默认回环监听、单API worker、串行模型生成。当前持有会话令牌的本地使用方式不等同账户权限系统。GPU限制在导入Torch前设置，最多两张可见卡；初版资源验收仅使用物理5，本轮中文适配资源见本页增量验收说明。模型和Conda环境复用外部既有目录，其余数据、代码、文档、报告、缓存、日志与临时文件在项目目录。

后续版本仍需历史交互时间切分、CF/重排训练、独立检索标注与锁定测试集、偏好长期存储、生产鉴权及容量验证。当前结果不能替代这些工作。
