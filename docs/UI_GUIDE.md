# ChoiceAgent 中文界面

界面通过 HTTP 调用本地核心服务，不加载模型、不导入 PyTorch，也不申请 GPU。默认连接 `http://127.0.0.1:8000`。

## 启动

先按项目主文档启动核心 API。然后在服务器另开一个终端：

```bash
cd /datas/wuxi/Projects/WorkSpace-RA
CHOICEAGENT_API_URL=http://127.0.0.1:8000 \
  /datas/wuxi/anaconda3/envs/my_rec/bin/python -m streamlit run \
  src/choiceagent/ui.py \
  --server.address 127.0.0.1 --server.port 8501 \
  --theme.base light --browser.gatherUsageStats false
```

浏览器打开 `http://127.0.0.1:8501`。远程使用时，可通过已有 SSH 连接把服务器 8501 端口转发到本机；默认不向公网暴露。核心 API 与 Streamlit 是两个服务，启动界面不会代替启动后端。

修改 `CHOICEAGENT_API_URL` 后重启界面。地址仅接受 HTTP/HTTPS，不接受内嵌用户名、密码或查询参数。用户界面不回显该环境变量，也不会回显后端异常原文。

## 使用顺序

1. 在“搜索商品”中输入商品或用途。中文快捷词会填入搜索框，再点击“找一找”。分类筛选显示中文名称，提交时仍使用资料库原有分类标识。
2. 在左侧设置历史美元预算、类别、排除品牌，必要时补充必须包含或排除的词。预算、匹配方式及“参考我的偏好”只用于搜索；聊天预算请直接写进消息。
3. 选择“喜欢”“不感兴趣”或“收藏”。重新搜索时，开启“参考我的偏好”可使用本次会话中的选择；界面不会假装旧结果已经重新排序。“移出清单”调用 `remove`，只撤回收藏，不删除喜欢或不感兴趣。喜欢和不感兴趣互相替换。
4. 在任意商品卡片选择“加入对比”。保留最近选择的两件，然后点击“比较这两件”，查看价格、品牌及类别。选择第三件会替换最早的一件。
5. 在“聊聊需求”中补充用途、预算或请求比较。回复附带的商品同样支持偏好和加入对比。
6. 商品卡片优先展示已提供的中文标题、分类和卖点，品牌保留官方名称；“查看英文原文”保留原始名称、卖点和规格。“查看资料依据”展开原始字段值与记录位置，比较表的原始值也可单独展开。没有中文适配内容的旧商品会提示查看原文，不会现场编造翻译。需要排查时，打开“高级：查看本次运行记录”，再点击读取按钮。

价格始终标为历史美元价，不是当前报价，不包含实时库存、运费或税费。缺少价格时显示“价格未提供”，不会按零美元处理；缺少规格也不会解释为商品没有该功能。界面不生成原始资料中不存在的评分、销量、图片或实时优惠。

## 会话与失败重试

- 首次连接仅自动尝试一次，成功后保存后端生成的随机会话标识。正常 Streamlit 重绘不会创建新会话或重复发送搜索、聊天、偏好与比较请求。
- 搜索和比较只在明确提交时发送；更改筛选条件不会自动执行搜索。聊天的 `request_id`、反馈的 `event_id` 在发送前保存到会话状态，失败后点击重试沿用原标识，由后端保证幂等。
- 未确认的聊天会保留原消息并暂停发送下一条；未确认的偏好会暂停其他偏好按钮。这样不会把超时误认为操作肯定失败，也不会通过反复点击创建新的重复事件。
- “刷新已保存的偏好”读取后端会话状态，不生成新反馈事件。“开始新的会话”另建独立会话，不删除后端旧记录。
- 同一浏览器连接内的界面重绘会保留记录；页面彻底刷新、连接重建或服务重启后不保证恢复旧会话。界面不把会话令牌写入 URL、浏览器持久存储或共享缓存。
- 连接超时为 3 秒，普通请求读取超时为 40 秒，聊天读取超时为 120 秒；无自动 POST 重试。服务忙、校验错误、资料失效、后端不可达和无效 JSON 均显示中文提示，保留已输入内容。后端恢复后由用户点击重试。
- 商品统计加载失败不阻断已建立的会话；此时分类/品牌筛选可能暂缺。没有匹配、检索不完整、功能降级分别显示提示，不会把部分结果包装为完整结果。

## 接口对应

| 界面操作 | 接口 |
| --- | --- |
| 初次连接 | `GET /health`、`POST /v1/sessions`、`GET /v1/catalog/stats` |
| 刷新偏好 | `GET /v1/sessions/{session_id}` |
| 搜索 | `POST /v1/search` |
| 对话与原请求重试 | `POST /v1/chat` |
| 喜欢 / 不感兴趣 / 收藏 / 移出清单 | `POST /v1/feedback` |
| 对比两件已看过的商品 | `POST /v1/compare` |
| 手动查看运行记录 | `GET /v1/traces/{trace_id}?session_id=...` |

运行记录仅按需读取；常见凭证字段、会话令牌、Bearer 凭证与 URL 中的凭证会遮盖。其余调试内容可能包括用户自己输入的查询和模型处理过程，请按本地单用户演示范围使用。

## 自检

使用 `my_rec` Python 运行界面测试，包括纯函数边界和中文展示交互：

```bash
cd /datas/wuxi/Projects/WorkSpace-RA
PYTHONPATH=src /datas/wuxi/anaconda3/envs/my_rec/bin/python -m pytest \
  tests/unit/test_ui_helpers.py -q
```

已使用 Streamlit 的 `AppTest` 配合模拟接口验证完整交互：后端不可达时正常显示重试；重绘不重复搜索；反馈超时重试保留同一 `event_id`；聊天超时重试保留同一 `request_id`，且不会多插入一条消息；移出清单保留喜欢状态；选中两件商品可比较；运行记录在点击读取前没有请求，读取后隐藏会话标识。该检查验证界面行为，不代替真实后端和模型的整体验收。

另外检查了 HTTP 错误、非 JSON 和错误 JSON 结构的友好提示，以及单独导入界面不会导入 `torch`。

## 真实浏览器录制

三个本地服务均启动后，可复现真实交互录制。首次使用先安装项目开发依赖中的 Playwright，再将浏览器放到项目运行目录：

```bash
cd /datas/wuxi/Projects/WorkSpace-RA
PLAYWRIGHT_BROWSERS_PATH="$PWD/runtime/browser" \
  /datas/wuxi/anaconda3/envs/my_rec/bin/python -m playwright install chromium
CUDA_VISIBLE_DEVICES='' \
  /datas/wuxi/anaconda3/envs/my_rec/bin/python scripts/capture_demo.py
```

脚本使用真实界面、核心 API 和本地模型，不拦截或模拟回复。它依次验证中文搜索、35 美元历史预算、喜欢、两件比较，以及聊天中从 35 美元修改为 20 美元；还检查回复后仍停留在聊天标签。浏览器通过参数禁用硬件 GPU，缓存放在 `runtime`。默认素材输出到 `reports/demo/final`，包括至少五张截图、原始 WebM、MP4 和 `ui_acceptance.json` / `ui_acceptance.md`。若完整录屏超过三分钟，MP4 会整体加速，报告记录倍速，原始 WebM 完整保留。使用 `--output-dir reports/demo/其他名称` 可以保留另一次验收。

加上 `--check-chinese --output-dir reports/localization/ui_final` 会额外检查中文商品标题、英文原文默认折叠且能展开、中文类别选择提交原始类别标识、收藏状态和两轮中文回答，并增加一张原文展开截图。此检查保留真实模型可能出现的澄清或无结果回复：没有返回价格时，预算推荐检查会记为未通过，不会用预设商品替换真实回复。完整商品翻译的验收应在翻译资料发布、服务更新后重新运行；早期规则回退截图不能作为完整翻译已完成的证据。

默认 `--chat-profile original` 使用完整长句请求；若需独立验证简短明确的请求，可另运行 `--chat-profile simple --check-chinese --output-dir reports/localization/ui_supported`。简短组依次发送“找桌面收纳，预算35美元”和“预算改到20美元”。两组报告分开保留，简短组通过不替代或覆盖长句组发现的问题。
